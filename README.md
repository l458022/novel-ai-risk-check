# 小说 AI 痕迹体检

面向中文网文作者的**离线 AI 痕迹自查工具**：指出哪些地方像 AI 写的、为什么像、可以往哪个方向改。

> ⚠️ **定位红线（不可越）**
> 1. 只做「AI 痕迹体检 + 提升文学质量的建议」，**不做**「降低 AI 检测率 / 规避平台审核」的工具
>    —— 后者违反《人工智能生成合成内容标识办法》**第十条**（禁止为隐匿生成合成痕迹提供工具）。
> 2. **不判定**「这篇是不是 AI 写的」，只给**痕迹强度**。
> 3. **不替写**、不生成替代文本。
> 4. **正文不上传**，全程离线运行。

---

## 快速开始

```bash
# 起一个静态服务器（任选其一）
python -m http.server 8801 --bind 127.0.0.1
# 然后打开 http://127.0.0.1:8801/web/index.html
```

或者直接双击 `web/index.html`（部分浏览器对 `file://` 下的模块加载有限制，建议用服务器）。

粘贴或拖入小说章节 → 点「开始体检」。

## 检测体系（5 层）

| 模块 | 检测项 | 对标平台违规类型 |
|---|---|---|
| **文体统计** | 句式波动、标点形态、用字丰富度、段落形态 | 行文机械、标点异常 |
| **对话分析** | 对话占比、对话长度波动 | 「活人味」不足 |
| **结构 / 水文** | 段落分布、情节推进 vs 描写配比、章末钩子 | 空洞水文、结构失常 |
| **叙事一致性** | 视角一致性、时间线、重复描写模板 | 前后文脱节、情节错乱 |
| **格式合规** | 提示词残留、Markdown 残留、全半角混用、引号混用、排版异常 | 格式混乱、排版错乱 |

## 逐句改写建议（`suggest.js`）

⚠️ **这是本工具与「只给笼统建议」的检测器最本质的区别**——
不说「标点要多样」，而是**定位到具体句子**并给出改写：

```
【第 5 句 · 优先处理】
  原文：他缓缓闭上眼睛，感受着体内那股陌生而强大的力量正在慢慢苏醒。
  改后：他闭上眼睛，感受着体内那股陌生而强大的力量正在苏醒。
   · 冗余修饰语「缓缓」删掉后句意不变
   · 冗余修饰语「慢慢」删掉后句意不变
   · 「感受着」是空转词，直接写感受本身
```

**四类可自动改写**（有明确替换结果）：

| 类型 | 例 | 处理 |
|---|---|---|
| 冗余修饰语 | 缓缓地、轻轻地、深深地、静静地 | 删除 |
| 凑字词 | 一丝、一抹、不由得、些许 | 删除 |
| 套话短语 | 嘴角勾起一抹弧度 → 笑了笑；深吸一口气 → 删除 | 替换 |
| 超长句（>34 字） | — | 在中间的「，」处断成两句 |

**三类只定位、给目标**（文学表达没有唯一正解，作者有权全部不改）：
连续同长句、句首重复、空洞表达（如「感受着」「仿佛在诉说」）。

## 标定与已知局限

**必读**：`docs/02-判据标定记录.md`

| | 真人基线 | AI 样本 |
|---|---|---|
| 来源 | 红楼梦 745 块（600 字/块） | 自建 11 段 |
| 中位分 | **11** | **48** |
| P90 | 27 | 78 |

**三条局限（必须知道）**：
1. **时代偏差**：真人基线是**清代白话**，与当代网文有差距 → 阈值偏保守，需用现代语料再校准。
2. **AI 样本仅 11 段**且由本项目作者手写，代表性有限。
3. **韵律文本**（诗、词、曲、赋）的统计特征天然接近 AI → 已加韵文检测打折，但仍有个别残留误报。

**踩过的坑**（详见标定记录）：
- TTR 有长度依赖 → 改用 **MSTTR**
- AI 样本用英文引号 → 被清洗正则删掉，标点特征虚假分离
- 诗词导致误报 → 新增**韵文检测**

```bash
node test/modules_test.js   # 25 项模块测试

```
